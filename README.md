# Nested Function Calls in C

This program demonstrates calling one function as an argument to another
function.

## File

nested_function_calls.c

## Concepts Used

- Function call
- Nested function calls
- Function arguments
- Return value

## How to Run

gcc nested_function_calls.c -o nested_function_calls
./nested_function_calls

## Sample Output

Original Number = 10
Result = 25
